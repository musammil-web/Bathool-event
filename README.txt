BATHOOL EVENTS - WEBSITE PACKAGE
================================

Upload ALL files to the ROOT (public_html / www / htdocs) of bathoolevent.com.
Keep file names exactly as they are - index.html links to them with /filename.

Files
-----
index.html           Main website (favicon, manifest and theme-color links added)
favicon.ico          Classic browser icon (16/32/48 px)
favicon-48.png       Small PNG icon
favicon-192.png      Android / Google search icon
favicon.png          512 px icon (PWA / high-res)
apple-touch-icon.png iPhone home-screen icon (180 px, dark background)
logo.png             Full logo - used in Google structured data
og-share-logo.png    1200x630 image for WhatsApp / Facebook / Twitter link previews
site.webmanifest     Mobile "Add to Home Screen" info
robots.txt           Search engine rules
sitemap.xml          Submit in Google Search Console

After uploading
---------------
1. Open https://bathoolevent.com/favicon.ico to check it loads.
2. Hard refresh (Ctrl+Shift+R) - browsers cache favicons for a long time.
3. Submit https://bathoolevent.com/sitemap.xml in Google Search Console.
4. To refresh WhatsApp/Facebook previews, use the Facebook Sharing Debugger.
